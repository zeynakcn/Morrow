MORROW — COMPLETE APP

All updates are already included. No update installer is needed.

1. Extract the ZIP and open morrow-app in VS Code.
2. Open Terminal > New Terminal inside that folder.
3. Run: npm run setup
4. Open .env and enter your OPENAI_API_KEY, then save.
5. Run: npm start
6. Open http://localhost:3000

Node.js 22.13+ required. No npm install needed for the included server.
